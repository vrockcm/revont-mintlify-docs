The authenticated Electron workspace uses a persistent sidebar. The exact items shown depend on enabled features, permissions, role, and whether custom models exist.

## Sidebar groups

| Group | Current surfaces |
| --- | --- |
| Home | Home |
| Communications | Meetings & Calendar, Emails |
| Core Modules | Actions, Clients, Deals, Contacts |
| Custom Models | Workspace-defined custom models |
| Insights | Analytics & Reports, Coaching |
| Administration | Organization Management, Knowledge Base, Audit, CRM Integrations |

The sidebar labels and order can be customized. The app also supports a collapsed rail and a More menu when the available height cannot show every group.

## Global controls

- **Search** opens the app's search and chat surface from any protected page.
- **Notifications** opens the notification center.
- **Settings** opens the full Settings dialog.
- **Collapse Sidebar** and **Expand Sidebar** change the navigation width.
- **Customize Sidebar** lets you adjust the navigation layout.
- **Reset to Defaults** restores the default navigation layout.
- **Done** saves an active sidebar customization session.

## Keyboard navigation

The current sidebar definitions include shortcuts for the primary pages. The exact shortcut reference is available in Settings → Keybinds, where saved application shortcuts can also be changed.

<Info>
  A page may be visible in the route table but still be unavailable in the sidebar for a particular user. Treat the visible app state and your assigned permissions as the source of truth.
</Info>
