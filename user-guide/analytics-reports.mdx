Analytics & Reports has a landing page for dashboards and a detail page for each dashboard.

## Dashboard landing page

The Reports page provides:

- a Favorites area when dashboards are favorited
- an All Dashboards list
- sorting by Recently Updated, Name, or Reports
- a control to create a dashboard
- actions to open, favorite, unfavorite, or delete dashboards

Creating a dashboard takes you into its detail page.

## Dashboard detail page

Dashboards have a view mode and an edit mode. In edit mode you can:

- add report widgets from the report catalog
- add native insight widgets
- select a widget to open its customizer
- drag, resize, and arrange widgets
- edit the dashboard title and description inline
- refresh the dashboard data

In view mode, the dashboard is a clean read-only grid. Use the available share control when you need to share the dashboard.

<Info>
  The available widget catalog and report entities are determined by the current application build and workspace data. The guide does not promise a fixed list of metrics.
</Info>
