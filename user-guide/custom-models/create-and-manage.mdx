---

Open **Settings**, then select **Data Model**.

## Create A Custom Model

<Steps>
  <Step title="Open Settings">
    Select **Settings** in the sidebar.
  </Step>
  <Step title="Open Data Model">
    In the settings panel, select **Data Model**.
  </Step>
  <Step title="Add an object">
    Select the control for adding a new object, then complete the object details.
  </Step>
  <Step title="Save the object">
    Save the object to add it to your data model and sidebar.
  </Step>
</Steps>

## Add A Field

<Steps>
  <Step title="Choose the object">
    In **Settings > Data Model**, select the object you want to change.
  </Step>
  <Step title="Add a field">
    Select the control for creating a new field.
  </Step>
  <Step title="Configure the field">
    Choose the field type and enter the requested settings.
  </Step>
  <Step title="Save the field">
    Save the field to add it to the object.
  </Step>
</Steps>

## Connect Objects

Use the data model relation controls when information in one object should connect to another object. The available relation types depend on the object and field configuration.
