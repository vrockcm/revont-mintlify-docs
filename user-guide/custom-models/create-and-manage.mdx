description: "Add custom models and fields for information unique to your business."
icon: "database"
---

Open **Settings**, then select **Data Model**.

## Create A Custom Model

<Steps>
  <Step title="Open Settings">
    Select **Settings** in the sidebar.
  </Step>
  <Step title="Open Data Model">
    In the settings panel, select **Data Model**.
  </Step>
  <Step title="Start the object wizard">
    Under **Workspace Objects**, select **Create**.
  </Step>
  <Step title="Complete Object Details">
    In the **Object Details** step, choose an **Icon**, enter a **Singular Name**, a **Plural Name**, and an optional **Description**. Select **Continue**.
  </Step>
  <Step title="Add fields">
    In the **Fields** step, enter a **Field Name**, choose its **Type**, and select **Add Field**. Repeat as needed, then select **Continue**.
  </Step>
  <Step title="Review and create">
    In the **Review** step, check the object and fields, then select **Create Object**.
  </Step>
</Steps>

The object appears in **Workspace Objects** and can appear in the sidebar when it is active and visible.

## Add A Field

<Steps>
  <Step title="Choose the object">
    In **Settings > Data Model**, select the object you want to change.
  </Step>
  <Step title="Open Fields">
    In the object editor, select the **Fields** tab.
  </Step>
  <Step title="Create the field">
    Select **Create Field**.
  </Step>
  <Step title="Configure and save">
    In the dialog, enter the field details, then select **Create Field**. When editing an existing field, the button is **Save Field**.
  </Step>
</Steps>

## Connect Objects

<Steps>
  <Step title="Open Relationships">
    In the object editor, select the **Relationships** tab.
  </Step>
  <Step title="Create the relationship">
    Select **Create Relationship** and complete the relationship dialog.
  </Step>
</Steps>
