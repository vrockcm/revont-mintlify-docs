Chat is available from global search and from many meeting and record pages.

## Start A Chat

<Steps>
  <Step title="Open Chat">
    Open the global Search bar. With no search text, choose **Ask Revont AI**. If you have entered a query or already have an open conversation, the action may appear as **Ask Revont about ...** or **Continue Chat**. You can also open Chat from a meeting, client, deal, or contact.
  </Step>
  <Step title="Check the context">
    Review the page or record you opened. That context helps Revont answer about the right work.
  </Step>
  <Step title="Ask a question">
    Type a plain-language question, press **Enter**, or select the **Send message** button.
  </Step>
  <Step title="Review the answer">
    Read the answer, source links, record cards, or other results Chat provides.
  </Step>
  <Step title="Continue or start over">
    Ask a follow-up question in the same conversation, or select the **New chat** control to begin fresh.
  </Step>
</Steps>

## Use Chat From A Meeting

Open a meeting, then use its Chat bar. Select **View transcript** when you need to check the meeting transcript while asking your question.

## Use Chat From An Email

Open **Communications Hub** from the sidebar, select **Emails** in the header, select a thread, and use the thread Chat area to ask about the conversation or draft follow-up.

<Note>
  Chat can only use the information your account is allowed to access.
</Note>
