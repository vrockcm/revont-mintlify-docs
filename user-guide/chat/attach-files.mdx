You can add a file when the answer needs information that is not already in Revont.

## Add A File

<Steps>
  <Step title="Open Chat">
    Open global Chat or the Chat bar on a meeting or record.
  </Step>
  <Step title="Select the attachment control">
    Select the paperclip attachment control.
  </Step>
  <Step title="Choose a file">
    Select a supported file from your computer.
  </Step>
  <Step title="Ask your question">
    Add your question and select **Send**.
  </Step>
</Steps>

You can attach up to three files in one request. Supported file types include PDF, Word, Excel, PowerPoint, CSV, JSON, Markdown, text, HTML, XML, common image formats, and other common business document formats.

<Note>
  Direct file uploads are limited to 50 MB per non-image file. Your workspace may apply additional access or storage limits.
</Note>
