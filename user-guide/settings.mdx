Open Settings from the sidebar. The dialog uses a left navigation and a scrollable content area.

## General

Control how Revont launches, meeting notifications, reminder timing, impromptu meeting detection, started-meeting notifications, and application updates.

## Voice

Choose the default microphone, inspect input level, and use the available input test controls.

## Integrations

Connect or disconnect Google, Microsoft, and Zoom. The connected-account area also exposes the email and calendar integration settings associated with the connected providers.

## Keybinds

Review and change the saved shortcuts for mute, stop recording, hide or show the overlay, open Settings, toggle mode, and toggle chat.

## Data & Storage

Use the data-management controls exposed for the local application data and storage lifecycle. The available actions depend on the current build and permissions.

## Profile

Manage your personal profile, avatar, password-reset flow, and account deletion flow. Account deletion requires explicit confirmation and schedules a grace period.

## Privacy

Start a personal data export from **Download My Data**. The export is delivered as a JSON download.

## Billing

Review the current subscription, seat usage, available plans, and subscription management actions. Some workspaces direct plan changes to the workspace administrator or sales.

## Support

Open help and documentation resources, view the app version, open third-party notices, and copy diagnostics to share with support.

## Data Model

Admins with the feature can inspect objects, field counts, object definitions, and relationships. Create or edit objects and fields from the model editor, or open the visualizer.

## Quotas

When enabled, admins can edit default targets, review attainment, filter quotas by scope or period, and add, edit, or delete explicit quota rows.

<Info>
  Data Model and Quotas are not shown for every account. Visibility is controlled by role and feature access.
</Info>
