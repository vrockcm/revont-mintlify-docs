Open **Audit** from the sidebar.

## Find An Event

<Steps>
  <Step title="Open Audit">
    Under **Administration**, select **Audit**.
  </Step>
  <Step title="Choose an activity area">
    Select the activity table that matches what you want to review.
  </Step>
  <Step title="Filter the results">
    Use the available filters to narrow the activity by time, user, event, or record.
  </Step>
  <Step title="Open the event">
    Select an event to open its detail panel.
  </Step>
</Steps>

Audit is read-only. What you can see depends on your organization access.
