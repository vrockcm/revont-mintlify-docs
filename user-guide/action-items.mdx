Actions is a master-detail page for follow-up work.

## Narrow the list

The page provides:

- status presets: **All**, **Pending**, **Overdue**, **Today**, **This week**, and **Done**
- search
- client and deal selectors
- team-member filtering
- **Group By** options for Flat, Client, Deal, and Due
- additional filters for priority and source
- due-date range filters

The selected filters are reflected in the page URL, so a reload can preserve the current view.

## Inspect an action

Select an item in the list to open its detail pane. The page can be opened from dashboard deep links with a selected action and intent.

Use the available detail controls to review the owner, linked records, due date, source, and status, then complete or update the work according to your permission level.

## Transfer data

Actions includes the shared data-transfer control for the action-item object when import or export is available to your account.
