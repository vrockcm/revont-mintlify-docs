Clients is the customer-account workspace. The page includes summary information, a searchable data grid, and a client detail route.

## Find a client

Use the search and data-grid controls to narrow the list. The grid supports sorting and field filters, and the page can switch between its available list and card presentations.

Select a row to open the client detail page. Use the row actions to edit a client or move it to the deleted view when your permissions allow it.

## Create and restore

Admins or users with the required write permission can use the page action to create a client. Deleted clients are separated into a Deleted view and can be restored by an eligible user.

## Related work

Client selectors appear in Communications Hub, Actions, Deals, and Contacts. Choosing a client usually narrows the related deal choices shown by that page.
