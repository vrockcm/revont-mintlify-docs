Deals is the pipeline workspace. Active deals are shown against the configured blueprint stages and can be reviewed in the available board or list view.

## Find deals

Use the deal search, client selector, owner filter, and the available scope controls. Admin users may also see **Archived** and **Deleted** views.

The active view supports additional data-grid or board filtering. The page keeps the selected filters while you work through the pipeline.

## Work the pipeline

Open a deal to view its detail page. Use the stage controls and the available board actions to move or reorder work. Admins with pipeline write access can open the blueprint builder from the settings control.

## Create, archive, and restore

Use the page action to create a deal when you have write access. Archived and deleted views expose their own restore actions when a record can be recovered.
