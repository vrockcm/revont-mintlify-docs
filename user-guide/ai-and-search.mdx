Revont's AI surfaces are available from the protected app shell and from the pages that own the underlying records.

## Search and chat

Open the global search and chat surface from the app shell. Use it to find workspace records or ask questions supported by the current data and permissions.

## Meeting memory

Meeting detail surfaces can include memory panels and evidence connected to the meeting. Read the supporting evidence before treating a generated memory or suggestion as final.

## Knowledge context

Knowledge Base articles can be used by connected AI surfaces when the workspace feature and permissions allow it.

<Info>
  The available prompts, suggestions, and answers are data- and permission-dependent. This guide describes the surfaces that own the workflow, not a fixed list of generated responses.
</Info>
