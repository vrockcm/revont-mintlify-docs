Open **Analytics & Reports** from the sidebar.

## Create A Dashboard

<Steps>
  <Step title="Open Analytics & Reports">
    Under **Insights**, select **Analytics & Reports**.
  </Step>
  <Step title="Select New Dashboard">
    Select **New Dashboard**.
  </Step>
  <Step title="Choose the dashboard type">
    In the dialog, select **Blank Dashboard** or choose one of the available templates.
  </Step>
  <Step title="Edit the dashboard">
    In the dashboard view, select **Edit Dashboard** to add reports and other widgets.
  </Step>
</Steps>

## Arrange A Dashboard

While the dashboard is in edit mode, select **Add a Widget** to add a report or insight card. Select a widget to customize it, then finish the dashboard edit when the layout is ready.

## Share A Dashboard

Open the dashboard and select **Share**. Choose the people who should be able to view it, then confirm the sharing change.

Use the dashboard list to open an existing dashboard. The list includes **Favorites** and **All Dashboards** when those sections contain dashboards.
