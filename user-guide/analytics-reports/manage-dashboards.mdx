Open **Analytics & Reports** from the sidebar.

## Create A Dashboard

<Steps>
  <Step title="Open Analytics & Reports">
    Under **Insights**, select **Analytics & Reports**.
  </Step>
  <Step title="Create a dashboard">
    Select the control for creating a dashboard.
  </Step>
  <Step title="Name the dashboard">
    Enter a name and complete the dashboard dialog.
  </Step>
  <Step title="Add reports">
    Add reports to the dashboard from the dashboard view.
  </Step>
</Steps>

## Arrange A Dashboard

Open the dashboard, then use its edit controls to move, resize, or customize the report cards. Save the dashboard when the layout is ready.

## Share A Dashboard

Use the dashboard sharing control to choose who can view it. Sharing options depend on your workspace permissions.
