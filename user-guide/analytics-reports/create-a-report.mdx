Open **Analytics & Reports** from the sidebar.

## Build A Report

<Steps>
  <Step title="Open Analytics & Reports">
    Under **Insights**, select **Analytics & Reports**.
  </Step>
  <Step title="Start a report">
    Select the control for creating a report.
  </Step>
  <Step title="Choose what to measure">
    Choose the record type, metric, grouping, date range, and filters requested by the report builder.
  </Step>
  <Step title="Choose a visualization">
    Select the chart or table style that best fits the question you are answering.
  </Step>
  <Step title="Save the report">
    Save the report when the preview shows the information you need.
  </Step>
</Steps>

## Add A Report To A Dashboard

Use the report action for adding the report to a dashboard, then choose an existing dashboard or create a new one when prompted.

<Note>
  The records and fields available in the report builder follow your workspace data model and permissions.
</Note>
