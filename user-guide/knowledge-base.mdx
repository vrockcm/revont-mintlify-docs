Knowledge Base is an admin-gated split-pane workspace. The left side owns the folder hierarchy. The right side owns the selected article or the empty state.

## Work with folders

Use the folder tree to expand and select folders. The tree supports drag-and-drop organization, and the page includes folder creation controls where the permission is available.

## Work with articles

Use **Create Article** to start a new article. Select an article in the tree to open it in the viewer or editor. The article surface can also expose import, pagination, and permission-aware actions.

## Search and related knowledge

Use the page search to narrow the knowledge tree. Knowledge articles can be referenced by other app surfaces, including chat and meeting-related workflows.

<Note>
  Knowledge Base is not visible to every user. The route requires the Knowledge Base feature, and write actions require the corresponding permission.
</Note>
