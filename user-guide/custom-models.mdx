Custom models are workspace-defined record types. When a custom model is active, visible, and readable for your account, it appears in the Custom Models sidebar group.

## Open a custom model

Select the model from the sidebar. The model page provides the record list and its available grid actions. Select a row to open the custom record detail page.

## Configure the data model

Admins with the custom data model feature and the required permission can open Settings → Data Model. That surface is where object definitions, fields, and relationships are inspected and changed.

<Note>
  Custom model labels, icons, fields, and relationships come from the workspace definition. This guide does not assume a particular model name.
</Note>
