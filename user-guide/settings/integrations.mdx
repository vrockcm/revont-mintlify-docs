Open **Settings > Integrations**.

## Connect A Mailbox And Calendar

<Steps>
  <Step title="Open Settings">
    Select **Settings** in the sidebar.
  </Step>
  <Step title="Choose Integrations">
    Select **Integrations** in the settings sidebar.
  </Step>
  <Step title="Choose a provider">
    Under **Connected Accounts**, choose **Connect** for Google or Microsoft.
  </Step>
  <Step title="Authorize access">
    Complete the provider sign-in and approve the requested access.
  </Step>
</Steps>

Google provides access to Gmail, Calendar, and Contacts. Microsoft provides access to Outlook, Calendar, and Contacts.

## Connect Zoom

In **Settings > Integrations**, find Zoom and select **Connect**. Complete the authorization flow to create and join Zoom meetings from Revont.

Use **Reconnect** if an existing connection needs to be authorized again. Use **Disconnect** only when you want to remove the connection.
