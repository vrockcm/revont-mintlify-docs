Open **Settings > Data Model**.

## Review Your Data Model

<Steps>
  <Step title="Open Data Model">
    Select **Settings** in the sidebar, then select **Data Model**.
  </Step>
  <Step title="Choose an object">
    Under **Workspace Objects**, select an object to open its editor. If no object is selected, the editor shows **Choose An Object**.
  </Step>
  <Step title="Review the object tabs">
    Review **Overview**, **Fields**, **Relationships**, **Quick Commands** when available, and **Settings**.
  </Step>
  <Step title="Review fields and relations">
    In **Fields**, review the information stored on each record. In **Relationships**, review the connections available from the object.
  </Step>
</Steps>

## Make Changes

- Select **Create** under **Workspace Objects** to start a new object.
- In an object editor, select **Create Field** to add a field.
- In **Relationships**, select **Create Relationship** to connect objects.
- In the object editor's **Settings** tab, use **Save Changes**, **Hide Object**, or **Show Object** as needed.
