Open **Settings > Data Model**.

## Review Your Data Model

<Steps>
  <Step title="Open Data Model">
    Select **Settings** in the sidebar, then select **Data Model**.
  </Step>
  <Step title="Choose an object">
    Select an object to review its definition.
  </Step>
  <Step title="Review fields">
    Review the fields available on the object and the information they store.
  </Step>
  <Step title="Review relations">
    Review the relations that connect the object to other objects.
  </Step>
</Steps>

Use the data model controls to add or change objects, fields, and relations when your permissions allow it.
