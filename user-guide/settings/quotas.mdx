title: "Quota Settings"
description: "Set quota defaults and review current quota attainment."
icon: "gauge"
---

Open **Settings > Quotas**.

## Review Quotas

Review **Default Targets**, **Current Attainment**, **Quotas**, and **Currency**.

## Set Default Targets

Update the default targets, then select **Save Defaults**.

## Add Or Edit A Quota

<Steps>
  <Step title="Open Quotas">
    Select **Settings** in the sidebar, then select **Quotas**.
  </Step>
  <Step title="Add a quota">
    Select **Add Quota**.
  </Step>
  <Step title="Set the quota">
    Enter the target and choose the **Currency**.
  </Step>
  <Step title="Save the quota">
    For a new or edited row, select **Save**. Select **Cancel** if you do not want to keep the change.
  </Step>
</Steps>

To change an existing row, select **Edit quota**. To remove it, select **Delete quota**.
