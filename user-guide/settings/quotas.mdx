Open **Settings > Quotas**.

## Review Quotas

Review **Default Targets**, **Current Attainment**, and the quota rows configured for your workspace.

## Add Or Edit A Quota

<Steps>
  <Step title="Open Quotas">
    Select **Settings** in the sidebar, then select **Quotas**.
  </Step>
  <Step title="Choose the quota">
    Select an existing quota or choose the control for adding a quota.
  </Step>
  <Step title="Set the target">
    Enter the target and choose the **Currency**.
  </Step>
  <Step title="Save the quota">
    Select **Save**.
  </Step>
</Steps>

Use the delete control on a quota row when you need to remove an existing quota.
