Open **Settings > Data & Storage**.

## Review Storage

The **Storage Usage** area shows the local database size and status.

## Manage Backups

<Steps>
  <Step title="Open Data & Storage">
    Select **Settings** in the sidebar, then select **Data & Storage**.
  </Step>
  <Step title="Review backup status">
    In **Data Backup & Recovery**, review **Auto-backup**, **Last Backup**, **Total Backups**, and **Available Backups**.
  </Step>
  <Step title="Create a backup">
    Select **Create Backup Now** when you want to make a new backup.
  </Step>
  <Step title="Restore a backup">
    On the backup row, select **Restore**. Review **Restore Database?**, then select **Restore** to confirm.
  </Step>
  <Step title="Delete a backup">
    On the backup row, select **Delete**. Review **Delete Backup?**, then select **Delete** to confirm.
  </Step>
</Steps>

<Note>
  Restoring a database changes the local data Revont uses and restarts the app after a successful restore. Confirm that you selected the correct backup before continuing.
</Note>
