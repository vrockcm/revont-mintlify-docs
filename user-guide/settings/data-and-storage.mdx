Open **Settings > Data & Storage**.

## Review Storage

The **Storage Usage** area shows the database size and current status.

## Manage Backups

<Steps>
  <Step title="Open Data & Storage">
    Select **Settings** in the sidebar, then select **Data & Storage**.
  </Step>
  <Step title="Review backup settings">
    Check **Auto-backup**, **Last Backup**, **Total Backups**, and **Available Backups**.
  </Step>
  <Step title="Manage a backup">
    Use **Delete** to remove a backup or **Restore Database** to restore the selected backup.
  </Step>
</Steps>

<Note>
  Restoring a database changes the local data Revont uses. Confirm that you have selected the correct backup before continuing.
</Note>
