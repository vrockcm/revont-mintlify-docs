The sidebar is the main way to move around Revont. It contains Home, Communications Hub, core modules, custom models, insights, and administration areas.

## Open A Page

<Steps>
  <Step title="Expand the sidebar">
    Select **Expand Sidebar** if the navigation is collapsed.
  </Step>
  <Step title="Choose a section">
    Under **Core Modules**, **Custom Models**, **Insights**, or **Administration**, select the page you need.
  </Step>
  <Step title="Open a custom model">
    Under **Custom Models**, select the model name to open its records.
  </Step>
</Steps>

**Home** is at the top of the sidebar. **Communications Hub** is its own sidebar area.

## Search And Chat

Select the global **Search** bar. Use it to find records, or open the Chat action when you want to ask Revont a question. The Chat action can appear as **Ask Revont AI**, **Ask Revont about ...**, or **Continue Chat**, depending on the current search and conversation.

## Customize The Sidebar

<Steps>
  <Step title="Open the sidebar menu">
    Right-click the sidebar.
  </Step>
  <Step title="Choose Customize Sidebar">
    Select **Customize Sidebar**.
  </Step>
  <Step title="Choose what to show">
    Drag items or groups into the order you want, then select **Done**.
  </Step>
</Steps>

To return to the standard navigation, right-click the sidebar and select **Reset to Defaults**.

## Communications Hub

Select **Communications Hub** in the sidebar to open the communications area. Select **Meetings & Calendar** in the expanded sidebar, or select **Meetings** in the page header. Select **Emails** in the header for email activity.

## Settings

Select **Settings** in the sidebar to open workspace settings. The settings panel contains separate tabs for **General**, **Voice**, **Integrations**, **Keybinds**, **Data & Storage**, **Profile**, **Privacy**, **Billing**, **Support**, **Data Model**, and **Quotas**.
