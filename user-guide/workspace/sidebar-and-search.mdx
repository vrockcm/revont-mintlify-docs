The sidebar is the main way to move around Revont. It contains your core modules, custom models, insights, and administration areas.

## Open A Page

<Steps>
  <Step title="Expand the sidebar">
    Select **Expand Sidebar** if the navigation is collapsed.
  </Step>
  <Step title="Choose a section">
    Under **Core Modules**, **Custom Models**, **Insights**, or **Administration**, select the page you need.
  </Step>
  <Step title="Open a custom model">
    Under **Custom Models**, select the model name to open its records.
  </Step>
</Steps>

## Customize The Sidebar

<Steps>
  <Step title="Open the sidebar menu">
    Select **More** in the sidebar.
  </Step>
  <Step title="Choose Customize Sidebar">
    Select **Customize Sidebar**.
  </Step>
  <Step title="Choose what to show">
    Select the modules you want visible, then finish the customization.
  </Step>
</Steps>

To return to the standard navigation, open **More** and select **Reset to Defaults**.

## Communications Hub

Select **Communications Hub** in the sidebar to open the communications area. From there, use the page tabs to switch between **Meetings & Calendar** and **Emails**.

## Settings

Select **Settings** in the sidebar to open workspace settings. The settings panel contains separate tabs for general behavior, accounts, data, profile, privacy, billing, support, data model, and quotas.
