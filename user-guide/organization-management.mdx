Organization Management is an admin-only page for members and pending invitations.

## Find people

Use the search field and role filter to narrow the unified member and invitation table. The table keeps its own internal scroll area so the page remains usable with large organizations.

## Manage access

The row action menu can expose role changes and removal or invitation-revocation actions. Select a member to open the user profile route when the page provides it.

Pending invitations can be revoked. Removing a member requires confirmation and should be done only after ownership of their work has been reviewed.

<Note>
  The exact role options and actions are permission-gated. If an action is not present, the current account is not allowed to perform it.
</Note>
