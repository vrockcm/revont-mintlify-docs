Organization Management is an admin-only page for members and pending invitations.

## Billing And Usage Controls

Organization admins also control the organization's seat subscription and pooled usage from this page:

- **Buy Seats** changes the Stripe subscription quantity. The server validates the requested quantity and Stripe webhooks reconcile the final seat count.
- **Pooled AI Credits** shows the organization's remaining balance, funded amount, and consumption by member. Credits are shared, so member rows show usage and share of pooled use, not a personal remaining balance.
- **Auto-Recharge** is required for active organizations. Admins choose a server-provided credit package and threshold. It cannot be disabled.
- **Meeting Usage** shows pooled Assisted and Unassisted hours. Unassisted hours use the documented weighted meter, and new meetings are blocked when the pooled allowance is exhausted in the initial rollout.

Payment-method status is redacted to card brand and last four digits. If a payment method is missing, use **Open Stripe Billing Portal** from the Auto-Recharge controls.

## Find people

Use the search field and role filter to narrow the unified member and invitation table. The table keeps its own internal scroll area so the page remains usable with large organizations.

## Manage access

The row action menu can expose role changes and removal or invitation-revocation actions. Select a member to open the user profile route when the page provides it.

Pending invitations can be revoked. Removing a member requires confirmation and should be done only after ownership of their work has been reviewed.

<Note>
  The exact role options and actions are permission-gated. If an action is not present, the current account is not allowed to perform it.
</Note>
