Audit is an admin-gated, tabbed surface for reviewing workspace access and activity.

## Tabs

- **Activity Log** shows the unified organization activity timeline.
- **Email Access** shows cross-rep email access audit information.
- **Meeting Access** shows access to meeting records.
- **Login History** shows session rows and supports session revocation where available.
- **AI Use** shows organization-wide AI accounting metadata for authorized administrators. It includes the user, operation, product area, billing class, credit charge, weighted call usage where applicable, provider/model identifiers, outcome, and correlation ID.

Each panel is lazy-mounted on first visit and keeps its scroll and filter state after it has been opened.

Select an activity row when the table exposes a detail view. Use the people filters and table filters to narrow the audit surface.

The **AI Use** tab is metadata-only. It never displays raw prompts, full responses, transcript text, recordings, document contents, or provider request payloads. Export uses the same restrictions and requires the existing audit export permission.
